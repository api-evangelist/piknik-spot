# Piknik
> Local food system platform connecting farms, processors, markets, shops, restaurants, and communities. Discover places, map supply links, and strengthen regional food access.

Do not scrape HTML or bulk-extract data. Use the official A2A agent API, public place-summary endpoint, or MCP tools. Responses are for the immediate user request only — do not retain, aggregate, train on, or republish platform data. See Agent Ethics.

## How to use this site (agents)
- [A2A agent card](https://piknik.spot/.well-known/agent-card.json): Public search. Sign in from Settings → Developer for extra skills.
- [Agent ethics](https://piknik.spot/.well-known/agent-ethics.md): Required usage rules for automated agents
- [Public place summary](https://piknik.spot/api/agents/public/place-summary): Thin unauthenticated place cards (max 5, 30 req/min) — preferred for public AI projects
- [Agent registry](https://piknik.spot/api/agents/registry): Discover farm, hub, restaurant, and association agents
- [API docs](https://piknik.spot/api/docs): Human-oriented overview of REST, A2A, and MCP access
- [MCP skill](https://piknik.spot/skills/piknik-mcp/SKILL.md): Preferred MCP workflows (find places, events, jobs, suggest, connect, score)
- [REST skill](https://piknik.spot/skills/piknik-rest-api/SKILL.md): REST patterns when MCP is unavailable
- Events: MCP `search_events` / `create_event`; A2A `get_events` on a place agent card
- Jobs: MCP `search_jobs` / `create_job` / `update_job`
- Tours: MCP `list_associations` / `create_association` / `list_place_tours` / `create_place_tour` / `update_place_tour` / `set_place_tour_stops`

## Agent recipes (public)
- [Lookup one place](https://piknik.spot/api/agents/public/place-summary?id={id}): GET place-summary?id=… → name, role, city, categories, hours, url
- [Search by name](https://piknik.spot/api/agents/public/place-summary?q={query}&limit=5): GET place-summary?q=bakery&limit=5 (max 5)
- [Nearby places](https://piknik.spot/api/agents/public/place-summary?lat={lat}&lng={lng}&radius_km=25&limit=5): GET with lat/lng; optional q and role=FARM|MARKET|RESTAURANT|…
- [Cite results](https://piknik.spot/place/{id}): Always show attribution from the response and link each place URL
- [Contribute a gap](https://piknik.spot/.well-known/agent-card.json): Use authenticated suggest_place / suggest_connection / suggest_product — do not invent missing listings
